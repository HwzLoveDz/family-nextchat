# 家庭站维护

唯一日常访问入口为 https://harveychat.dpdns.org/。

## 旧入口退役

Vercel 项目使用一条免费自定义防火墙规则：请求的 `host` 不等于
`harveychat.dpdns.org` 时拒绝访问。规则覆盖备用域名、Vercel 默认域名、
分支别名和历史部署 URL，包含页面、API 与 WebSocket 握手。
域名绑定和历史部署保留为平台内部的所有权及回滚记录，不作为访问入口。
不要只删除域名绑定后留下指向 Vercel 的 DNS 记录。

规则配置保存在 [entry-firewall.json](../scripts/family/entry-firewall.json)。
它是运维配置，不会由应用构建自动发布。修改时保留项目已有的其他规则，
仅更新这条规则，并核对正式域名的页面、登录 API、附件和语音握手。

需要验证隔离 Preview 时，只在维护期间为该次具体部署域名添加例外，
保留 Vercel 登录保护，验收完立即撤销例外。Preview 使用独立数据库，
不能为了预览连接生产数据库。

## 本地与历史材料

- 当前源码、功能和安全测试位于本仓库。
- `.env.local` 是被 Git 忽略的当前本地私有配置。
- 工作区 `outputs/` 保存已经交付的截图与验收报告，既有链接继续有效。
- 工作区 `archive/2026-11-04/work-history/` 保存早期调研、过程日志和阶段脚本。
  归档脚本可能固定旧 Preview、依赖原路径并包含付费防重跑检查，不能直接运行。
- 缓存、构建产物、手机工具和原始可编辑基线按原位置保留。

日常使用 README 中的构建、离线测试，以及 `scripts/family/` 中的维护工具。
数据库升级只使用现行管理员流程或迁移工具，不执行历史验收初始化脚本。
